token-lifecycle

@startuml
title Життєвий цикл токена у DataflowRuntime

skinparam shadowing false
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #334155
}

[*] --> Queued : push(edge.queue)

Queued : токен очікує\nна дузі DFG
Queued --> Delivered : t_now - token.t >= edge.delay\n/onToken

Delivered : токен доставлено\nдо вузла-приймача
Delivered --> Inbox : inbox[nodeId][portId] = token

Inbox : токен очікує\nінших вхідних портів
Inbox --> Ready : усі порти заповнені\nreadyAt[node] <= t_now

Ready : вузол готовий\nдо активації
Ready --> Fired : consume inputs\n/onBeforeFire + onFire

Fired : виконання compute(node.kind)
Fired --> Emitted : token.t = t_now + node.latency

Emitted : вихідні токени\nстворено
Emitted --> Queued : push(outgoing edge.queue)

Fired --> Sinked : якщо вузол sink\n/onOutput
Sinked --> [*]
@enduml
